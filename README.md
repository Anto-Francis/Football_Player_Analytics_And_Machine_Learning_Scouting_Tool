# Football Scouting Tool

A football scouting tool for analysing player statistics.

## Features

- Compare players using position-specific or general statistics.
- Find players with similar statistical profiles.
- Group players into clusters using K-Means.
- View cluster statistics and players.
- Visualise clusters using a 2D PCA graph.
- Find top players for a selected statistic.

## Data

- `players_data-2024_2025.csv` — Original dataset: from https://www.kaggle.com/datasets/hubertsidorowicz/football-players-stats-2024-2025
- `players_cleaned.csv` — Cleaned dataset used for the project.
